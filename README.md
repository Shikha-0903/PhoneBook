# 📞 Flutter PhoneBook App

A simple and efficient PhoneBook application built using **Flutter** and **Hive** (a lightweight, NoSQL local database).  
This app was created for interview demonstration purposes to showcase CRUD (Create, Read, Update, Delete) operations in Flutter.

---

## 🚀 Features

- ➕ Add New Contact
- 📝 Update Existing Contact
- ❌ Delete Contact
- 📋 View All Saved Contacts

The app uses **Hive** for fast, secure, and offline local data storage.

---

## 🛠️ Tech Stack

- 💙 **Flutter** — UI Toolkit for building cross-platform apps.
- 🐝 **Hive** — Lightweight & blazing-fast NoSQL database for Flutter.
- 📱 **Dart** — Programming language for Flutter.
